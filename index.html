CraftFlowPublisher

A small, self-hosted tool for publishing and scheduling pins on my own Pinterest business account.

What it does

  • Creates pins from my own content library (images, titles, descriptions, links).
  • Schedules pins to be published at planned times.
  • Reads my own boards so I can choose where each pin is posted.
  • Shows basic performance stats for my own pins.

Who uses it

This is a personal tool. It runs privately in a Docker container on my own infrastructure, is used only with my own Pinterest account, and is not offered to the public or to other Pinterest users.

How it connects to Pinterest

The app uses the official Pinterest API v5 with OAuth 2.0. Access can be revoked at any time from Pinterest settings under Security & logins → Apps.
